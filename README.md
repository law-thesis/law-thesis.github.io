# Occupational Gender Bias in LLMs

Interactive results from my MSc thesis at the University of Copenhagen (2026).

Audits GPT-5, Mistral Large 2.1, and DeepSeek-V3.2 across 565 ACS occupations 
using Total Variation Distance from parity. Introduces SEFAT, a contextual 
intrinsic bias metric for decoder-only transformers.
